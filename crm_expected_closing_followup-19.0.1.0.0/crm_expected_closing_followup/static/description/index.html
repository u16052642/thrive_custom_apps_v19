CRM Expected Closing Followup

Automatically track missed expected closing dates and notify responsible managers.

  • Detects opportunities where expected closing date has passed (based on previous date)
  • Sends alerts to CRM Closing Followup Manager group users
  • Supports daily automated reminders via scheduled action
  • Improves sales pipeline visibility and follow-up tracking
  • Fully integrated with standard Odoo CRM workflow

Step 1

Go to CRM Pipeline

Step 2

Create or manage opportunities with expected closing dates.

Step 3

System automatically detects overdue records and triggers alerts using cron.

Manager Group Configuration

Configure users in the CRM Closing Followup Manager group to receive notifications.

Notification View

Managers receive alerts for overdue opportunities and take timely action.
